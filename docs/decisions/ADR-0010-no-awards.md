# ADR-0010: No awards in this version

- Date: 2026-11-25
- Status: accepted

## Context

The CV draft includes an awards table. The published site already distinguishes awarded grants from other CV material.

## Decision

Do not add awards in this version. Do not add the CV awards table to data or to the timeline.

## Rationale

Owner's decision on 2026-11-25. Awards stay out of scope for the timeline addendum.

## Consequences

There is no awards data file and no awards section. Timeline types are education, position, publication, and milestone. Milestones are the awarded grants already in `data/grants.yaml`, not prizes.
